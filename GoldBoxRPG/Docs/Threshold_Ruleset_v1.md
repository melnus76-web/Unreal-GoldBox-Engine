# The Threshold System
## An Original Tactical RPG Ruleset
### Version 1.0 — Design Reference

---

## 0. Purpose and Design Philosophy

This document defines a complete, original ruleset to replace the AD&D-derived placeholder rules used during the engine's vertical slice development. Every number, table, and named mechanic below was designed from scratch for this project — none of it is transcribed from any published tabletop rulebook. Where a mechanic serves a similar *purpose* to something familiar from classic tactical dungeon-crawl RPGs (because that purpose is genre-standard, not because it was copied), the specific numbers, breakpoints, and names are original.

The system keeps the things that made the genre work: six ability scores, a handful of archetypal classes, level-based growth, Vancian-style memorized spellcasting, and a "descending target number" combat feel (your skill makes a number go *down*, rather than adding a bonus to your roll). It deliberately departs from familiar conventions in several places — ascending Defense Rating instead of descending Armor Class, three saving throws instead of five, formula-driven spell slots instead of a memorized table, no percentile "exceptional ability score" subsystem — both to give the system its own identity and to ensure nothing here resembles a specific published table.

"The Threshold System" is a placeholder name. Rename freely.

> **Build status (updated during GB-079):** Ability Scores (§1), Combat (§4), and the XP threshold formula in Leveling (§6) are fully implemented and tested in the actual Blueprints — Might, Vigor, Reflex, Acuity, Resolve, Presence are live on `SCharacter`, `ResolveAttack` runs the percentage-based resolution in §4, and `BPL_RulesLibrary.GetXPThreshold` computes XP thresholds via the `500 × Level × (Level−1) × ClassMultiplier` formula rather than reading `DT_LevelProgression`'s `XPRequired` column (that column is now unused, kept for reference only). The rest of Leveling (Hit Dice, level-up procedure) and Saving Throws (§5), Classes (§3), Conditions (§7), Morale (§8), and Magic (§9) are still design-only — the project runs on the original legacy placeholder math for those. See `GoldBox_Solo_Dev_Build_Order.md` GB-079 for what's left.

## 1. Ability Scores

Six scores, generated by rolling 3d6 per score (range 3–18), assigned in any order, or via a 75-point buy array if you prefer a non-random method: `[16, 14, 13, 12, 10, 8]`.

| Score | Abbr. | Governs |
|---|---|---|
| Might | MGT | Melee damage, to-hit bonus, carry capacity |
| Vigor | VIG | Hit point bonus, Fortitude saves |
| Reflex | RFX | Defense Rating bonus, ranged accuracy, initiative |
| Acuity | ACU | Arcane spellcasting power, skill points |
| Resolve | RES | Divine spellcasting power, Willpower saves |
| Presence | PRS | Morale, leadership, social checks, henchman limit |

### Might Bonus Table
| Might | To-Hit | Damage |
|---|---|---|
| ≤ 4 | −2 | −2 |
| 5–7 | −1 | −1 |
| 8–12 | 0 | 0 |
| 13–15 | +1 | 0 |
| 16–17 | +1 | +1 |
| 18 | +2 | +2 |

### Vigor Bonus Table (Hit Points per Level)
| Vigor | HP Bonus |
|---|---|
| ≤ 4 | −2 |
| 5–7 | −1 |
| 8–11 | 0 |
| 12–14 | +1 |
| 15–16 | +2 |
| 17 | +3 |
| 18 | +4 |

No "exceptional ability score" percentile subsystem — 18 is simply the top of the range. Magic items and rare boons may push a score above 18 at the GM's discretion, in which case bonuses continue extrapolating the pattern above (+1 per 2 points).

## 2. Races

Human, Elf, Dwarf, Gnome, Half-Elf, Halfling, Half-Orc. These are unchanged from the existing project — they're generic fantasy archetypes with no distinctive mechanical identity tied to any specific published ruleset, so no redesign was needed here. Racial mechanical modifiers (stat adjustments, special abilities) are out of scope for this document and can be layered on separately without touching anything below.

## 3. Classes

Four core classes, matching the existing test party. Five additional hybrid classes are sketched at the end of this section for future expansion (the class enum already reserves slots for them).

### Warden (martial)
Best Hit Dice (d12), best Defense Rating from heavy armor, gains extra attacks fastest, weakest at Acuity/Resolve-based saves unless built for it. +2 Fortitude save.

### Devout (divine caster)
Good Hit Dice (d8), Vancian spellcasting from the Divine list (memorizes from Resolve), moderate armor proficiency, can heal allies and turn back undead-equivalent creatures. +2 Willpower save.

### Adept (arcane caster)
Worst Hit Dice (d6), Vancian spellcasting from the Arcane list (memorizes from Acuity), no armor proficiency without a feat/talent, highest ceiling on raw magical damage and utility. +2 Willpower save.

### Rogue (skill specialist)
Good Hit Dice (d8), best skill access, Ambush Strike bonus damage, light armor only, gains extra attacks at moderate pace. +2 Reflex save.

### Extra Attacks Per Round
| Class | Level 1–4 | Level 5–7 | Level 8–10 |
|---|---|---|---|
| Warden | 1 | 2 | 2 (+ rerolls 1s on damage) |
| Rogue | 1 | 1 | 2 |
| Devout | 1 | 1 | 2 |
| Adept | 1 | 1 | 1 |

(No fractional "attacks every other round" bookkeeping — every breakpoint is a clean integer.)

### Ambush Strike (Rogue)
When attacking an unaware or flanked target: +4 to hit, and damage multiplier as below.

| Rogue Level | Damage Multiplier |
|---|---|
| 1–3 | ×2 |
| 4–6 | ×3 |
| 7–9 | ×4 |
| 10 | ×5 |

### Hybrid Classes (sketch — flesh out when built)
- **Warden-Devout hybrid** ("Templar"): d10 HD, Divine casting up to spell level 3, heavy armor, fewer extra attacks than pure Warden
- **Warden-Rogue hybrid** ("Skirmisher"): d10 HD, no spellcasting, Ambush Strike at half the Rogue's multiplier, full martial attack progression
- **Devout-Rogue hybrid** ("Shadowpriest"): d6 HD, Divine casting up to spell level 3, Ambush Strike at half multiplier, light armor
- **Wilderness caster** ("Warden of the natural Divine list" — equivalent role to a nature-focused divine caster): d10 HD, Divine spellcasting from a nature-flavored subset, light/medium armor, animal companion talent
- **Specialist Rogue** ("Infiltrator" — equivalent role to a lethal skill-specialist): d6 HD, no spellcasting, Ambush Strike multiplier one tier ahead of base Rogue, trades skill breadth for single-target lethality

## 4. Combat: Strike Number and Defense Rating

> **Revision note:** this section originally specified a d20 roll against `Strike Number − Defense Rating`. That formula was wrong — with Defense Rating ascending, subtraction makes better-armored targets *easier* to hit, the opposite of the intent. During implementation (GB-079) this was replaced entirely with a percentage-based roll, which also turned out to be far more forgiving to calibrate as more bonus sources (gear, spells, conditions) get added later. The version below is what's actually built.

### The Core Roll
Roll 1d100 (percentile). Compare against the attacker's **Final Hit Chance**:

```
Final Hit Chance = clamp(Strike Number + Might Bonus + Weapon Bonus + Situational Modifier − Defense Rating, 5, 95)
```

Hit if the roll is **less than or equal to** Final Hit Chance. The clamp guarantees a floor of 5% and a ceiling of 95% regardless of how lopsided the level/gear gap is — this replaces the natural-20/natural-1 special-casing a d20 system would need.

### Strike Number (SN)
An ascending hit-chance baseline against a totally undefended target (Defense Rating 0). Starts at **50** for every class at level 1 and rises with level at a class-specific pace:

| Class | SN improves by… |
|---|---|
| Warden | +5% per level |
| Rogue | +4% per level |
| Devout | +4% per level |
| Adept | +3% per level |

A level 10 Warden reaches SN 95 (50 + 9×5); a level 10 Adept reaches SN 77 (50 + 9×3).

### Defense Rating (DR)
Ascending — higher is better. Starts at 0 (unarmored, no shield, no Reflex bonus) and rises with gear and Reflex, now expressed directly as a percentage-point reduction to the attacker's hit chance:

```
Defense Rating = Armor Value + Shield Value + Reflex Modifier
```

| Armor | Value | Movement Penalty |
|---|---|---|
| None | 0% | none |
| Padded/Light Cloth | 5% | none |
| Leather | 10% | none |
| Studded Leather | 15% | none |
| Chain Shirt | 20% | −1 tile/turn |
| Chain Mail | 25% | −1 tile/turn |
| Banded Mail | 30% | −2 tiles/turn |
| Plate Mail | 35% | −2 tiles/turn |
| Shield (any) | 5% | none |

Reflex Modifier uses the same breakpoint shape as the Might table (§1) but scaled to percentage points: ≤4: −2%, 5–7: −1%, 8–12: 0%, 13–15: +1%, 16–17: +1%, 18: +2%. Applied fully regardless of armor weight — heavy armor's cost is paid in movement speed, not in losing your Reflex bonus.

### Putting It Together
A level 3 Warden (SN = 50 + 2×5 = 60) attacking a target in Chain Mail with average Reflex (DR = 25 + 0 = 25) gets: `Final Hit Chance = 60 − 25 = 35%`. Roll 1d100, hit on 35 or below.

### Initiative
Roll 1d6 per side, add Reflex Modifier. Higher total acts first this round. Re-roll each round (no fixed turn order across the whole encounter).

### Monster Conversion Reference
Monster Strike Number/Defense Rating are authored directly per monster (no level/class formula — they're not leveling characters). When converting or designing new monster stats, a rough guide: a "level N equivalent" monster should sit near that level's class SN, and Defense Rating should land wherever its narrative armor/toughness implies on the table above. There's no requirement that monster numbers follow the formula precisely — hand-tune for the encounter difficulty you want.

## 5. Saving Throws

Three categories, each tied directly to an ability score, calculated by formula rather than a per-level lookup table:

```
Save Target = 16 − floor(Level / 2) − Ability Modifier − Class Bonus (if applicable)
```

Roll 1d20 ≥ Save Target to succeed.

| Save | Governing Score | Resists |
|---|---|---|
| Fortitude | Vigor | Poison, disease, physical hardship, exhaustion |
| Reflex | Reflex | Traps, breath-weapon-style area effects, falling |
| Willpower | Resolve | Charm, fear, domination, mind-affecting magic |

Class bonuses (+2 to one save, listed in §3): Warden→Fortitude, Devout→Willpower, Adept→Willpower, Rogue→Reflex.

Example: a level 6 Devout (Resolve modifier +2, class bonus +2 Willpower) facing a fear effect: `Save Target = 16 − 3 − 2 − 2 = 9`. Needs a 9 or better on 1d20.

## 6. Hit Points and Leveling

### Hit Dice by Class
Warden d12, Devout d8, Rogue d8, Adept d6 — rolled once per level, plus the Vigor Bonus (§1) each time. At level 1, take the maximum die result rather than rolling, so starting characters aren't crippled by a bad first roll.

### Experience Thresholds
Every class uses the same base formula, scaled by a class multiplier — no memorized table, easy to extend past level 10 if needed:

```
XP Required for Level N = 500 × N × (N − 1) × ClassMultiplier
```

| Class | Multiplier |
|---|---|
| Rogue | 0.9 |
| Warden | 1.0 |
| Devout | 1.1 |
| Adept | 1.2 |

| Level | Warden | Rogue | Devout | Adept |
|---|---|---|---|---|
| 1 | 0 | 0 | 0 | 0 |
| 2 | 1,000 | 900 | 1,100 | 1,200 |
| 3 | 3,000 | 2,700 | 3,300 | 3,600 |
| 4 | 6,000 | 5,400 | 6,600 | 7,200 |
| 5 | 10,000 | 9,000 | 11,000 | 12,000 |
| 6 | 15,000 | 13,500 | 16,500 | 18,000 |
| 7 | 21,000 | 18,900 | 23,100 | 25,200 |
| 8 | 28,000 | 25,200 | 30,800 | 33,600 |
| 9 | 36,000 | 32,400 | 39,600 | 43,200 |
| 10 | 45,000 | 40,500 | 49,500 | 54,000 |

(Table shown for designer convenience — derive it from the formula in code rather than hardcoding it, so balance tweaks only require changing the multiplier.)

### Level-Up Procedure
On crossing a threshold: increase Level, roll new Hit Die + Vigor Bonus and add to MaxHP and CurrentHP, recompute Strike Number from the class table in §4, recompute spell slots if applicable (§9).

## 7. Conditions

| Condition | Effect |
|---|---|
| Restrained | Cannot move; attackers gain +4 to hit this target |
| Paralysed | Cannot act or move; attackers automatically hit |
| Poisoned | Fortitude save each round or lose 1d4 HP |
| Blinded | −4 to hit, −4 Defense Rating, −4 on Reflex saves |
| Quickened | +1 extra attack this round, +1 tile movement |
| Slowed | −1 attack this round (minimum 1), −1 tile movement |
| Diseased | Vigor score reduced by 1 per day until cured |
| Sapped | Permanent reduction of 1 character level (rare; powerful undead-equivalent only) |
| Petrified | Treated as Paralysed; immune to further damage except force/sonic-equivalent effects |
| Unconscious | Cannot act; treated as Paralysed for incoming attacks |
| Dead | Removed from initiative; eligible for Rekindle (§9) if cast in time |

Conditions tick at the start of the affected combatant's turn unless otherwise noted.

## 8. Morale

Monster groups (not player characters) check morale on: first casualty in the group, more than half the group dead, or the group's leader killed.

```
Roll 2d6 + Presence Modifier of the group's leader (if any)
```

| Result | Outcome |
|---|---|
| ≤ 6 | Group flees, moving away from the party each turn until off the grid |
| 7–9 | Group holds but fights defensively (−2 to hit) |
| ≥ 10 | Group holds firm, no effect |

## 9. Magic System (Vancian)

Two schools — **Arcane** (Adept, governed by Acuity) and **Divine** (Devout, governed by Resolve). Both work identically from a slot-tracking perspective: memorize specific spells during rest, expend the matching slot to cast, slots refresh after a full rest.

### Spell Slots by Formula
No memorized table — slots per spell level are derived directly from caster level:

```
Slots(SpellLevel, CasterLevel) = clamp(CasterLevel − 2 × (SpellLevel − 1), 0, 4)
```

Maximum spell level available = `min(5, ceil(CasterLevel / 2))`.

## 10. Skills (Rogue)

Percentile-based (roll d100, succeed on a result ≤ your skill rating). Base rating at level 1, +5 per level thereafter, capped at 95%.

| Skill | Base % |
|---|---|
| Stealth | 35 |
| Sleight of Hand | 30 |
| Disable Device | 25 |
| Climb | 40 |
| Perception | 30 |

Other classes may attempt these at a flat 5% base, improving only through magic items or rare talents — Rogues are meant to be the only class that reliably succeeds.

## 11. Implementation Mapping (for the eventual Blueprint refactor)

This is not part of the ruleset itself — it's a working note for whoever (you, future you) ports this into the existing Blueprint structure, so nothing gets lost in translation.

| Old (AD&D-derived) | New (Threshold System) |
|---|---|
| THAC0 | Strike Number (SN) — now an ascending hit-chance percentage, combined with Defense Rating via addition then subtracted, not a descending d20 target number |
| AC (descending) | Defense Rating (DR) — ascending, expressed as a direct percentage-point reduction |
| `GetStrengthBonus` | `GetMightBonus` — new breakpoints, no exceptional-STR percentile tier |
| `GetConstitutionHPBonus` | `GetVigorBonus` — new breakpoints, max +4 instead of +3 |
| DT_LevelProgression (XP column) | Replace with formula: `500 × N × (N−1) × ClassMultiplier` — no hardcoded table needed |
| DT_LevelProgression (THAC0 column) | Replace with formula: `16 − floor(Level / ClassSNDivisor)` |
| DT_SavingThrows (5-category table) | Replace with formula: `16 − floor(Level/2) − AbilityMod − ClassBonus`, 3 categories |
| ECharacterClass (Fighter/Cleric/MagicUser/Illusionist/Thief) | Warden/Devout/Adept/Rogue (+ 5 hybrid slots, see §3) |
| ESaveType (5 values) | 3 values: Fortitude, Reflex, Willpower |
| ECondition.Held | Restrained |
| ECondition.Hasted | Quickened |
| ECondition.LevelDrained | Sapped |
| Backstab table | Ambush Strike table, §3 |
| Spell slot table (per roadmap GB-047/048) | Formula-driven, §9 — no DT_SpellSlots table needed, compute on demand |

Struct field names (`THAC0`, `AC` on `SCombatant`/`SCharacter`) can stay as-is internally if renaming them is too disruptive mid-project — what matters legally and creatively is the *values* and *public-facing terminology*, not private variable names only you ever see.
